# BACKEND DE LA APP HECHO CON  FASTAPI

Para correr el backend se necesita **uv** 

- Descargar **uv**

- Una vez instalado *uv* escribir en la terminal desde este directorio 
```bash
    uv run fastapi dev
```

El diccionario con los datos se encuentra en ```/ingest```; comparar información con la que se encuentra en el directorio ```backend\src\services\data.csv```
